# Load Balancer

![](Imgs/load_balancer_single_point_of_failure.png)

- **Problem:** Single server hardware limits (vertical scaling) vs. horizontal scaling.
- **Solution**: Distribute traffic across multiple identical server instances using a Load Balancer.
- **Trade-off**: Introduces a single point of failure (load balancer) requiring high availability/backup strategies.

So in real systems, the Load Balancer itself also has a backup which is more stuff to run.

![](Imgs/Backup-LoadBalancer.png)

For the load balancer to send any request to any server, all your servers have to be interchangeable. Any of them has to be able to handle any request.
