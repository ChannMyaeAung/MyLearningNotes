# Claude.md

## Purpose

A markdown-based configuration file that automatically loads project-specific instructions at the start of every session. In professional software engineering, maintaining persistent project context is critical for AI-assisted development. Using `CLAUDE.md` or `agents.md` allows developers to provide the AI agent with a centralized "source of truth" regarding project rules, architectures, and standards.

## Persistent vs. Temporary Data

- `CLAUDE.md`: Contains intentional project facts, stack preferences (e.g., `pnpm`, `Drizzle`), design system rules, and testing procedures.
- `Auto-memory`: Managed by *Claude* to store lessons learned during development (e.g., local setup quirks)

## Key Engineering Benefits:

- **Elimination of Redundant Instructions:** Instead of manually reminding an agent to use specific tools (e.g., `pnpm`, `Drizzle ORM`, or specific testing frameworks) in every new session, these project facts are automatically loaded by the agent upon initialization.
- **Scalable Architecture:** As projects grow, you can implement tiered instruction files. This includes:
  - **Personal Instructions:** Located in a global `.claude` folder, applied across all your repositories.
  - **Project-Level Instructions:** Stored in the root directory and committed to Git, ensuring every contributor and AI agent follows the same project-wide standards.
  - **Local Overrides:** The use of `.claude.local.md` for environment-specific configurations (e.g., local sandbox URLs) that should remain excluded from version control.

## **Best Practices for Implementation:**

- **Be Specific:** Move beyond vague quality goals. Instead, define concrete constraints such as "use two-space indentation" or "run `pnpm test` before finalizing tasks" to reduce hallucinations.
- **Modularize Rules:** For complex codebases, utilize the `additional_rules` directory to split instructions by domain such as `testing.md`, `database.md`, or `security.md` to keep the active context window clean and focused.
- **Automation:** Use the `init` command within *Claude Code* to generate an initial baseline based on your existing `package.json` and project structure, which you can then refine to match your specific engineering workflow.

By treating these markdown files as essential documentation, you ensure that the AI agent acts as a consistent member of the engineering team rather than an isolated tool.
