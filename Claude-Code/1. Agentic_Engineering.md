# Agentic Engineering with Claude Code

Moving from simple prompting to a structured, scalable engineering system. The goal is not to have an AI write code blindly but to build an engineering system where I act as the architect, directing specialized agents through standardized, verifiable workflows.

## Core Engineering Pillars

1. **Project Foundations & Context:**
   - Utilize `CLAUDE.md` and `agents.md` files for persistent, project-wide instructions
   - Define explicit permission controls to ensure agent actions remain safe and predictable.
2. **Strategic Planning**:
   - Use `Plan Mode` for high-stakes technical decisions (e.g., database schema, migrations, or large refactors) to validate the approach before code generation.
3. **Reusable Workflows (Skills)**:
   - Implement `Skills` to encode repeatable process such as UI creation or debugging as modular procedures that load only when relevant.
4. **Security & Verification**:
   - Integrate *Code Rabbit* for **AI Deep Scans** to audit the entire repository for security risks and vulnerabilities, ensuring the codebase remains robust as it scales.
5. **Scalability with Sub-agents**:
   - Delegate independent investigations to **sub-agents** to prevent context window saturation while parallelizing tasks.
